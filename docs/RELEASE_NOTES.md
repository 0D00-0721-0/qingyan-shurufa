清言 0.6.6 预览版支持 Apple Silicon（M 系列）Mac，系统要求 macOS 14 或更高版本。请下载 `QingType-0.6.6-arm64.dmg`。

## 本版更新

- **模糊拼音**支持独立选择 10 组双向规则，适用于内置简繁全拼、小鹤双拼及雾凇拼音，默认关闭。关闭总开关会保留已选规则。
- **清言设置**可从输入菜单或访达打开，设置窗口不占 Dock 图标。
- **雾凇更新**分为检查和确认安装两步。发现更新时显示官方包的更新时间和大小，确认后才下载、校验和部署。成功部署并核验旧资源后，保留一个托管回退点，历史备份可在访达查看。
- **保存并应用**只重写发生变化的配置文件，减少雾凇词库索引的重复编译。
- 修复部分候选展开后的标点提交，以及 Caps Lock、回车和小键盘 Enter 在组合输入中的处理。应用更新检查使用当前的 GitHub 仓库地址。

## 安装与验收范围

打开 DMG，将「清言.app」拖入「应用程序」，然后在「开始使用」中安装或更新输入法。基础输入可离线使用。雾凇与万象由用户选装，设置、词库、模型和学习数据存放在 `~/Library/QingType`。

本包使用临时签名，Apple Developer ID 签名与公证尚待完成。发行页附 SHA-256 校验文件和源码包，构建来源可在应用的 `Resources/BuildInfo.json` 核对。

跨应用打字、多显示器、休眠恢复和干净 Mac 上的完整安装与卸载仍需逐项验收。卸载前应先在系统键盘设置移除清言输入源。旧编译缓存如果仍引用先前的万象模型，启动校验可能暂时停用模型；基础输入可以继续使用。

许可、依赖与验收范围见仓库的 `THIRD_PARTY.md`、`docs/DEPENDENCIES.md` 和 `docs/COMPATIBILITY.md`。
